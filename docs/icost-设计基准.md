# iCost 设计基准与分期实现计划

> 参考对象：[iCost 记账](https://icostapp.com/)（App Store：[id1484262528](https://apps.apple.com/cn/app/id1484262528)），一款 iOS 平台闭源记账应用。
> 调研日期：2026-09-03。功能清单来自 App Store 应用介绍与版本更新说明；设计分析基于 App Store 公开展示截图。
> 本项目**仅借鉴其信息架构、交互与视觉风格**，全部代码与素材均为原创，未复制任何 iCost 代码、图标或图片。

## 一、iCost 功能全清单（App Store 提取）

快速记账、分类管理（二级分类/自定义分类）、资产管理（多类型/隐藏/归档/排序）、图表分析、iCloud 备份、Excel 导出、30+ 平台账单导入、截图导入（支付宝/微信/云闪付）、深色模式、锁屏/桌面小组件、收支日历、预算管理（周/月/年总预算+分类预算）、FaceID/密码保护、秒开模式、URL Scheme、模板快捷记账、退款关联、报销管理、多账本（创建/修改/复制/归档）、多币种（50+）、记账图片/位置、周期入账、消费分期、资产对账、存钱计划（灵活/定额）、记账标签、组合付款、智能记账（截屏/文本/语音）、批量操作、账单搜索（时间/金额/账本/账户/标签）。

## 二、iCost 的设计语言（截图分析）

1. **信息架构**：底部四栏 —— 明细 / 资产 / 日历 / 图表；记账入口悬浮独立。
2. **明细页**：账本切换（页首）+ 月份切换器（← 2023年9月 →）+ 支出/收入/结余汇总 + 按日分组流水。
3. **资产页**：净资产大卡（总额 + 可见性眼睛 + 总资产/总负债小字）→ 账户按组展示（资金/信用/储值账户），组头右侧有组内余额合计，账户行 = 彩色圆标 + 名称/副标题 + 右侧余额。
4. **日历页**：月历格子内直接显示当日支出（红）/收入（绿），点选日期看当日流水。
5. **图表页**：周/月/年/全部/范围 分段控件 + 期间切换箭头；收支统计卡（支出/收入/结余/**日均支出**）；环形图**中心显示总额、外侧标注「分类+百分比」**，底部支出/收入切换；净资产趋势曲线。
6. **快捷记账**：计算器式数字键盘 + 分类宫格 + 账户选择；大色块按钮（支出红/收入绿/转账黄/模板蓝）；「撤回最近一笔」。
7. **整体视觉**：iOS 原生风 —— 大标题、圆角卡片分组列表、彩色圆形分类图标、系统分段控件、留白克制。

## 三、分期实现计划

### ✅ 第一批（本次已实现，v0.2）

| iCost 特性 | pocket-ledger 实现 |
|---|---|
| 四栏信息架构（明细/资产/日历/图表） | 底部 Tab 与桌面侧边栏均改为四栏 |
| 明细页月份切换 + 汇总 | MonthSwitcher 组件 + 月度三卡 |
| 预算管理（简化：月度总预算） | 按账本设置月度总预算，进度条 + 超支告警（分类预算待后续） |
| 快捷记账数字键盘 | 底部抽屉：大字金额 + 分类宫格 + 计算器键盘（⌫/C/完成） |
| 收支日历 | 月历格内显示当日收支，点选看当日流水，支持账本筛选 |
| 图表页周期（周/月/年/全部 + 前后切换） | 分段控件 + MonthSwitcher，「全部」自动按月聚合（上限 24 个月） |
| 日均支出指标 | 收支统计第四卡 |
| 环形图中心总额 + 外侧百分比标签 | ECharts title 居中 + label formatter |
| 净资产卡可见性眼睛 | 隐私模式，全页金额脱敏为 ¥✱✱✱✱ |

### ✅ 第二批（交互增强，v0.3）

- ✅ 转账：账户间划转，双向更新余额、不计入收支、不影响净资产
- ✅ 模板快捷记账：记账面板「⭐ 存为模板」+ 明细页模板芯片一键再记 + 模板管理
- ✅ 周期记账：每天/每周/每月/每年规则，启动时自动补齐（幂等去重、追账上限 60 条、大小月自适应如 1/31→2/28）
### ✅ 第三批前段（搜索 / 标签 / 报销，v0.4）

- ✅ 账单搜索：关键词（备注+标签）+ 类型/账本/账户/标签/日期范围/金额区间/报销状态多维筛选，命中数与支出收入汇总，结果内直接编辑

### ✅ 第三批后段（退款关联，v0.5）

  修复部分 WebView 中画布文字被回退为宋体、与页面字体不一致的问题
### ✅ 深色主题（提前实现，v0.6）

- ✅ 全应用双主题：CSS 变量切换（背景/卡片/输入/键盘/分割线/阴影全套变量），`color-scheme` 同步
- ✅ ECharts 深度适配：轴/网格/图例/环形图描边与中心文字/tooltip 随主题切换，深色下主色提亮（#7288ff）保证对比度
- ✅ 顶栏与侧边栏 🌙/☀️ 切换按钮，主题选择持久化，状态栏 theme-color 跟随

### ✅ 资产模块对齐 iCost（账户类型体系，v0.7）

- ✅ 六大账户大类：资金 / 信用 / 充值 / 理财 / 应收 / 应付，65 个子类型（品牌色圆标），
  「＋添加账户 → 选择类型」手风琴选择；旧数据自动迁移（v1 → v2 persist migrate）
- ✅ 资产页分组折叠：组头右侧「余额 / 欠款」汇总，账户行 = 圆标 + 名称 + 子类型/备注 + 「不计入」徽标 + 余额
- ✅ 账户详情页：账户卡（更多菜单 编辑/删除、✏️ 余额调整按差额改期初）+ 按月折叠流水
  （月/日 流出流入汇总、每笔之后的账户余额、转账路线、时间）+ 右上角「记一笔」预填本账户
- ✅ 借入 / 借出：总借入/总借出卡 + 独立列表页（借入/借出分段、借款时间、＋直达类型选择）
- ✅ 账户开关：`计入总资产`（不计入净资产/汇总/趋势图）、`记账时可被选择`（记账/转账/周期账户选择器过滤）
- ✅ 「全部收支记录」从资产页迁至明细页（跨账本 + 账本标记 + 类型筛选）
- ✅ 负债账户余额口径统一：余额 = 欠款额，消费增加欠款、还款/退款减少欠款

- 🔜 组合付款（多账户组合支付）

## 四、与 iCost 的刻意差异

- **响应式 Web**：iCost 是 iOS 原生 App；本项目面向 Web，桌面端使用侧边栏布局而非照搬 Tab Bar。
- **零后端**：iCost 依赖 iCloud 同步；本项目默认纯本地，云同步放第三批且做成可选。
- **开源 MIT**：iCost 闭源免费+内购；本项目完全开源，数据格式（JSON 导出）公开可迁移。
